## Global Constraints

- Python wylacznie z `.venv`: `.venv/bin/python -m pytest ...`,
  `.venv/bin/python -m ruff ...`, `.venv/bin/python -m mypy ...`, CLI
  `.venv/bin/kartograf`.
- Brama przed KAZDYM commitem: `.venv/bin/python -m pytest tests/ -m "not live" -q`
  zielone, `.venv/bin/python -m ruff check .` i
  `.venv/bin/python -m ruff format --check .` czyste,
  `.venv/bin/python -m mypy kartograf/ tests/` bez bledow.
- Commit WYLACZNIE przez straznik wzorcow:
  `F="$HOME/.config/kartograf/forbidden-patterns.txt"; test -r "$F" && ! git diff --cached -U0 | grep '^+' | grep -qiEf "$F" && git commit ...`.
  Brak pliku wzorcow = zatrzymaj sie i zapytaj. Tresci wzorcow nie
  wpisuj do repo ani nie wypisuj.
- Commity: Conventional Commits z opisem po polsku, autor
  `Daldek <git@debever.pl>`, BEZ stopki `Co-Authored-By` (`CLAUDE.md`).
  Docstringi i komentarze po angielsku; dokumentacja po polsku bez
  diakrytykow (jak reszta `docs/`, poza `USAGE.md`, ktory ma diakrytyki);
  komunikaty CLI polskie bez diakrytykow.
- Kazde zadanie zmieniajace zachowanie dopisuje wpis do `docs/CHANGELOG.md`,

  `### Naprawione`; zmiana widoczna dla uzytkownika — z dopiskiem, co
  zrobic). Zadania wylacznie z docstringami/testami — bez wpisu.
- Testy offline; fixtury z SUROWYCH odpowiedzi; testy nie przypinaja
  brzmienia komunikatow (asercje na fragment niosacy fakt: liczby, flagi,
  nazwy). Dane pobierane na zywo: poza repo i poza `/tmp`, z jawnym
  `--output`; CLI z korzenia repo.
- Numery linii w zadaniach = stan `develop` z 2026-10-09 (`0.7.2-dev`);
  po wczesniejszych zadaniach moga sie przesunac — szukaj po symbolu.

    def _variant_hints(self, parser: SheetParser) -> set[str]:
        """Hints naming other variants (resolution, vertical CRS) of the
        product whose index has this sheet (P10). Advisory: a failed query
        is logged and gives no hint - never changes the no-coverage result."""
        hints: set[str] = set()
        query_bbox = self._query_bbox(parser)
        for resolution, by_crs in self.WMS_SKOROWIDZE_ENDPOINTS.items():
            for vertical_crs, endpoint in by_crs.items():
                if (resolution, vertical_crs) == (self._resolution, self._vertical_crs):
                    continue
                try:
                    found = self._variant_has_sheet(
                        parser, endpoint, float(resolution[:-1]), query_bbox
                    )
                except DownloadError as e:
                    logger.warning(
                        "%s: nie sprawdzono wariantu %s %s: %s",
                        parser.godlo, resolution, vertical_crs, e,
                    )
                    continue
                if found:
                    hints.add(self._variant_hint(resolution, vertical_crs))
        return hints
