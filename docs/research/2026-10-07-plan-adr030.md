> **Dla agentow wykonawczych:** WYMAGANY SUB-SKILL: `superpowers:subagent-driven-development`

> nowa funkcja, bez shimow zgodnosciowych (BREAKING w CHANGELOG).

**Cel:** `--campaigns {newest,all}` i `--min-year` dla NMT/NMPT/orto PL (oraz LAZ),
pliki kampanii w `<segment>/kampanie/<data>_<id>/...`, sciezka standardowa jako
atomowe dowiazanie do najnowszej lokalnej kampanii; `newest` przy kazdym
uruchomieniu sprawdza nowsza kampanie.

**Architektura:** Provider (mixin skorowidza) rozwiazuje LISTE rekordow
(`resolve_campaigns`) i pobiera pojedynczy rekord (`download_record`);
`DownloadManager` sklada sciezke kampanii (`FileStorage.get_campaign_path`),
pobiera brakujace kampanie, pisze sidecar kampanii i wola
`download/links.py::ensure_standard_link` (symlink wzgledny -> hardlink ->
kopia, `os.replace`). Tozsamosc kampanii (`CampaignRef`) jest czysta funkcja
rekordu (`download/campaigns.py`). Cache listy rekordow: nowa tabela
`campaigns_cache`. Providery bez kampanii (atrapy, obce `BaseProvider`) ida
dotychczasowym torem "plik w sciezce standardowej".

**Tech stack:** Python 3.12, pytest (offline, `-m "not live"`), ruff, mypy,
SQLite (WAL), rasterio/GDAL (odczyt przez dowiazania).

**Spec:** `docs/DECISIONS.md` ADR-030 (CRLF — nie edytowac), uzupelnia
ADR-026 (segmenty), ADR-027 (wycinek), ADR-028 (wybor rekordu), ADR-029 (LAZ).

**Stan wyjsciowy (zmierzony 2026-10-07):** develop `e875e60`, **2406 testow

## Global Constraints

- Strategie: `newest` (domyslna) i `all`; odrzucone `coverage`, `mosaic`, `--campaign <id>` — nie implementowac.
- Regula `newest` = ADR-028 BEZ ZMIAN: pierwsza warstwa z dopasowaniem, w niej max `(aktualnosc, dt_pzgik or "", url)`, bez preferencji `full_sheet`.
- `all` = kazdy rekord przechodzacy twardy filtr ADR-028 (godlo jako token, uklad + strefa PL-2000, rozdzielczosc 1 m/5 m dokladnie, pion przez endpoint, kolor orto), ze WSZYSTKICH warstw.
- Katalog kampanii `<data>_<id>`: `<data>` = `aktualnosc` (RRRR-MM-DD), `<id>` = pierwszy segment liczbowy nazwy pliku w URL (`83233_1744736_<godlo>.asc` -> `83233`), inaczej `u` + 8 znakow hex `sha1(URL)`.
- Plik kampanii: `<segment>/kampanie/<data>_<id>/<hierarchia godla>/<godlo>.<ext>` + `<plik>.meta.json`; segment ADR-026 bez zmian (takze `orto/pl_1992_cir`).
- Prawdziwe pliki NMT/NMPT/orto leza WYLACZNIE w `kampanie/` (obie strategie).
- Sciezka standardowa `<segment>/<hierarchia>/<godlo>.<ext>` = dowiazanie do najnowszej LOKALNEJ kampanii (takze niepelnej); metoda: 1) symlink WZGLEDNY, 2) hardlink, 3) kopia + `Warning:`; podmiana atomowa (tymczasowe dowiazanie + `os.replace`); `extra.link` = `symlink|hardlink|copy`.
- Kontrola istnienia sprawdza CEL dowiazania (wiszace = brak pliku).
- Brak migracji: zwykly plik w sciezce standardowej = nieznany; `newest` pobiera do `kampanie/` i ZASTEPUJE go (z sidecarem) dowiazaniem.
- `--min-year RRRR`: granica z roku `aktualnosc` (nie `dt_pzgik`), obie strategie; `newest` + najnowsza starsza od granicy = `NoCoverageError` z data najnowszej kampanii.
- Rok z nazwy warstwy sluzy wylacznie do POMINIECIA zapytania (gorny rok < granicy); warstwa bez roku zawsze odpytywana; o wyniku decyduje `aktualnosc`.
- `campaigns_cache`: klucz jak `record_cache`, TTL 7 dni, `--force` = `MetadataCache(refresh=True)`; `--min-year` NIE wchodzi do klucza.
- Sidecar kampanii: `extra.campaign = {id, date, zgloszenie, source, full_sheet, dt_pzgik}` obok `extra.source`; `request.campaigns` (+ `request.min_year`); `extra.link` w sidecarze sciezki standardowej.
- Wycinek PL `--target-crs` + `--campaigns all` = `ValidationError`/`Error:` kod 1 PRZED siecia; wycinek z `newest` czyta arkusze przez dowiazania.
- CZ: jawne `--country cz` + (`all` lub `--min-year`) = `Error:` kod 1; pod `--country auto` = `Info:` (dotyczy tylko PL).
- LAZ: `newest` = ADR-029; `all` = bez deduplikacji ADR-029; `--min-year` = dolna granica `akt_rok`; `--min-year` i `--year` wykluczaja sie; uklad LAZ bez zmian, bez dowiazan.
- Dane testow na zywo tylko na `<katalog-danych>/...` (jawne `-o`), cache SQLite lokalnie (cwd = repo); testy pytest offline.
- `Info:`/`Warning:`/`Error:` na stderr, `-q` ich nie tlumi.

### 1.3 `kartograf/download/links.py` (NOWY)

```python
LinkMethod = Literal["symlink", "hardlink", "copy"]

@dataclass(frozen=True)
class LinkOutcome:
    method: LinkMethod
    target: Path      # plik kampanii wskazywany przez sciezke standardowa
    changed: bool     # dowiazanie utworzone/przestawione w tym wywolaniu

def link_atomic(target: Path, link: Path) -> LinkMethod:
    """Ustaw `link` -> `target`: symlink WZGLEDNY (os.path.relpath), potem
    os.link, potem shutil.copyfile; zawsze przez tmp w katalogu `link`
    (f"{link.name}.{pid}_{tid}.link.tmp") + os.replace. Wyjatki proby
    (OSError, NotImplementedError, ValueError z relpath na Windows) = nastepna
    metoda; tmp sprzatany. Porazka kopii (OSError) wylatuje."""

def campaign_key_from_sidecar(data_path: Path) -> tuple[str, str, str] | None:
    """(extra.campaign.date, extra.campaign.dt_pzgik or "", extra.source.url)
    z <data_path>.meta.json; None gdy brak/nieczytelny/niepelny."""

def linked_campaign(link: Path) -> Path | None:
    """Plik kampanii, na ktory wskazuje sciezka standardowa; None = brak,
    wiszace dowiazanie, zwykly plik bez extra.link (stary plik — (e)),
    hardlink ktory nie jest juz tym samym plikiem (samefile), kopia o innym
    rozmiarze niz cel."""

def write_standard_sidecar(link: Path, target: Path, method: LinkMethod) -> None:
    """<link>.meta.json = sidecar celu + extra.link=method +
    extra.link_target=<relpath POSIX od link.parent>; ZWYKLY plik, tmp +
    os.replace (zastepuje takze symlink). Sidecar celu nieczytelny ->
    stary sidecar standardowy usuniety + logger.warning. Nigdy nie wyjatek."""

def ensure_standard_link(
    link: Path, target: Path, key: tuple[str, str, str], *, refresh: bool = False
) -> LinkOutcome:
    """Dowiazanie standardowe do najnowszej LOKALNEJ kampanii:
    cur = linked_campaign(link); cur_key = campaign_key_from_sidecar(cur).
    Zostaw (changed=False), gdy cur istnieje, cur_key is not None,
    cur_key >= key i NIE (refresh and cur == target). Inaczej link_atomic +
    write_standard_sidecar + usun <link>.aux.xml (stale statystyki GDAL PAM).
    Gdy zostaje, a <link>.meta.json brak — odtworz go. method przy
    changed=False: symlink gdy link.is_symlink(), inaczej extra.link
    sidecara standardowego."""
```

## 2. Rozstrzygniecie otwartego punktu ADR (g)

**Przeglad `_fetch_wms_layers` (`skorowidz.py:378-421`):** iteruje WSZYSTKIE elementy
`Name` dokumentu GetCapabilities; `LAYER_PATTERN.fullmatch` jest jednoczesnie
filtrem przynaleznosci do produktu i parserem roku. Realne GetCapabilities
(0.2) zawieraja `default`, `WMS`, a dla orto `SkorowidzeOrtofotomapyZasiegi*`
(zasiegi, bez URL-i). `query_skorowidz_layer` (`:213-257`) rzuca
`DownloadError`, gdy odpowiedz nie jest szablonem skorowidza, a
`_resolve_record` (ADR-028) wymaga odpowiedzi KAZDEJ probowanej warstwy.

**Decyzja planu: warstwa niepasujaca do `LAYER_PATTERN` NIE jest odpytywana;
nazwa z rodziny produktu daje `logger.warning`.**

- Nowy atrybut klasy `LAYER_FAMILY`: NMT `^SkorowidzeNMT`, NMPT `^SkorowidzeNMPT`,
  orto `^SkorowidzeOrtofotomapy(?!Zasiegi)`. Nazwa z rodziny niepasujaca do
  `LAYER_PATTERN` -> `logger.warning("Warstwa %s z %s: nieznany schemat nazwy
  (LAYER_PATTERN) — NIE odpytywana; zgloszenie: aktualizacja wzorca", ...)`.
  Nazwy spoza rodziny (`default`, `WMS`, `Zasiegi*`) — cicho, jak dotad.
- Uzasadnienie: (1) odpytanie dowolnej nazwy zamieniloby zmiane schematu
  nazw w CALKOWITA awarie (`DownloadError` dla kazdego arkusza: `default`/
  `Zasiegi` nie oddaja szablonu); (2) warstwa bez sparsowanego roku nie ma
  miejsca w kolejnosci "od najnowszej", od ktorej zalezy `newest` (ADR-028:
  pierwszy pasujacy rocznik konczy szukanie) — wstawienie jej na poczatek albo
  koniec moze zmienic wybor kampanii po cichu; (3) gdy GUGiK zmieni schemat
  calkowicie, `if not layers:` (`:416-420`) daje juz glosny `DownloadError`;
  ostrzezenie pokrywa przypadek czesciowy (nowa warstwa obok starych), ktory
  dzis znika bez sladu — to jest dokladnie wymog (g) "nie gubic danych bez sladu".
- Konsekwencja dla zdania ADR (g) "warstwa ... o nazwie niepasujacej do wzorca
  jest odpytywana zawsze": w kodzie nie ma warstw "odpytywanych, ale bez roku
  z wzorca" poza `Starsze` (pasuje do wzorca orto, grupa 1 = None) — to one sa
  "odpytywane zawsze" przy `--min-year`. Do potwierdzenia: Q1.

**Pomijanie warstw przy `--min-year` (g):** tylko w `all` (`_resolve_all`):
`upper = layer_upper_year(LAYER_PATTERN, name)`; pomin, gdy `upper is not None
and upper < min_year`. W `newest` warstwy NIE sa pomijane (Q5): wybor konczy
sie na pierwszej warstwie z dopasowaniem, wiec pominiecie oszczedza zapytania
wylacznie wtedy, gdy wynik i tak bedzie brakiem pokrycia — a pelne
rozwiazanie daje dokladna date najnowszej kampanii do komunikatu (f) i
pozwala zapisac `record_cache` bez zaleznosci od granicy (h).

**Cache przy pominietych warstwach (`all`):** payload `campaigns_cache` niesie
`scanned_from` (None = wszystkie warstwy). Trafienie jest wazne dla zadania
z granica `M`, gdy `scanned_from is None or (M is not None and scanned_from <= M)`;
inaczej chybienie i pelne/szersze skanowanie nadpisuje wpis. Klucz bez granicy (h).

def _fetch_campaigns(self, godlo, skip_existing, on_download):
    std = self._storage.get_path(godlo, self._default_ext)
    records = self._provider.resolve_campaigns(godlo, campaigns=self._campaigns, min_year=self._min_year)
    downloaded, reused, local, errors, started = [], [], [], [], False
    for record in records:
        ref = CampaignRef.from_record(record)
        path = self._storage.get_campaign_path(godlo, ref, ref.extension or self._default_ext)
        if skip_existing and path.exists():
            reused.append(path); local.append((ref, path)); self._note_reuse(path); continue
        if on_download is not None and not started:
            on_download(); started = True
        try:
            self._provider.download_record(record, path)
        except NoCoverageError:
            raise
        except DownloadError as e:
            errors.append((ref, e)); continue
        self._write_campaign_sidecar(path, godlo, record, ref)
        downloaded.append(path); local.append((ref, path))
    linkable = [(r, p) for r, p in local if p.suffix.lower() == self._default_ext.lower()]
    outcome = None
    if linkable:
        ref, path = max(linkable, key=lambda rp: rp[0].sort_key)
        outcome = ensure_standard_link(std, path, ref.sort_key, refresh=path in downloaded)

## 7. Pytania otwarte (proponowane rozstrzygniecia — NIE zgadywane w kodzie bez zgody)

- **Q1 (g) — warstwa o nazwie niepasujacej do `LAYER_PATTERN`.** ADR: "jest odpytywana zawsze" (przy `--min-year`) i zostawia decyzje planowi. Propozycja: NIE odpytywac, `logger.warning` dla nazw z rodziny produktu (sekcja 2). Odpytywanie dowolnych nazw rozbiloby kazdy arkusz (`default`, `WMS`, `Zasiegi*` nie oddaja szablonu -> `DownloadError`) i nie ma dla nich miejsca w kolejnosci `newest`. Do potwierdzenia + ewentualna errata zdania ADR.
- **Q2 — `--target-crs` + `--min-year`.** ADR (j) wymienia tylko `all`. Nazwa pliku wycinka nie niesie granicy, a skip wycinka po istnieniu pliku zwrocilby wycinek zbudowany pod inna granica. Propozycja: `Error:` kod 1 przed siecia (jak `all`); alternatywa: dopuscic (arkusze starsze -> nodata + `missing_sheets`) z dopiskiem `min_year` do `request` i nazwy — wiecej kodu bez zgloszonej potrzeby.
- **Q3 — kampanie `.xyz` (stare NMT, np. 72675).** Propozycja: plik kampanii z rozszerzeniem z URL (`<godlo>.xyz`), dowiazanie tylko do kampanii w formacie providera; `newest` z `.xyz` (dzis zapisywany jako `.asc` — blad) -> plik w `kampanie/`, link bez zmian, ostrzezenie. Alternatywa: pomijac `.xyz` w `all` z ostrzezeniem.
- **Q4 — skip wycinka PL pod `newest`.** ADR (b) dotyczy arkuszy; wycinek dalej pomijany po istnieniu pliku wyniku, wiec nie zobaczy nowszej kampanii bez `--force`. Propozycja: bez zmian w 0.7.0 (wycinek jest produktem pochodnym; `--force` przebudowuje), zapis w CHANGELOG/ARCHITECTURE. Alternatywa: porownanie `sheet_sources` z biezacymi rekordami (siec przy kazdym skip).
- **Q5 — pomijanie warstw przy `newest --min-year`.** Literalnie (g) dotyczy obu strategii; propozycja: tylko `all` (sekcja 2) — w `newest` oszczednosc dotyczy wylacznie wynikow "brak pokrycia", a pelne rozwiazanie daje date najnowszej kampanii w komunikacie (f) i nie miesza granicy z `record_cache` (h).
- **Q6 — wolumen `all` dla orto.** N-34-139-A-c-1-1 RGB: 10 kampanii (0,05–0,75 m; pojedynczy plik 0,05 m siega GB). Propozycja: bez limitu, `Info:` z liczba kampanii i arkuszy przed pobraniem w trybie `all` (wymaga rozwiazania rekordow przed petla — dodatkowy przebieg resolve w CLI z cache) ALBO tylko dokumentacja + zalecenie `--min-year`. Rekomendacja: dokumentacja (bez dodatkowego przebiegu).
- **Q7 — sidecar sciezki standardowej: dowiazanie czy zwykly plik.** ADR (d): sciezka i "jej sidecar .meta.json wskazuja plik i sidecar najnowszej kampanii"; (i): "extra.link w sidecarze sciezki standardowej". Symlinkowany sidecar nie moze niesc `extra.link` innego niz sidecar kampanii, a `_note_reuse`/`os.replace` i tak zastapilyby symlink plikiem. Propozycja: ZWYKLY plik = kopia sidecara kampanii + `extra.link` + `extra.link_target` (odtwarzany przy kazdym przestawieniu). Do potwierdzenia + errata (d).
- **Q8 — `request.min_year` przy braku granicy.** Propozycja: `request.campaigns` zawsze (pliki kampanii), `request.min_year` tylko gdy podane (wzor E16 LAZ); LAZ: `request.campaigns` tylko gdy `all` (sidecary `newest` LAZ bez zmian).
- **Q9 — godlo CZ pod `--country auto` z `all`/`--min-year`.** Litera (j): `Info:` (opcja dotyczy tylko PL). Godlo jednoznacznie wskazuje kraj, wiec rownie dobrze moglby to byc blad jak jawne `--country cz`. Propozycja: `Info:` (litera ADR).
- **Q10 — czesciowa porazka `all` dla arkusza.** Propozycja: arkusz = twarda porazka (`failed`, kod 1, "ponow pobranie"), pobrane kampanie zostaja, link na najnowsza pobrana. Alternatywa: sukces z `Warning:` — sprzeczna z R5 ("kazda twarda awaria -> kod 1").
