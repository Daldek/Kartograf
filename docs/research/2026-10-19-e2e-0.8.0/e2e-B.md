# Raport E2E - plaster B: imagery, maps, geodesy (Kartograf 0.8.0, develop e019126a)

## Zakres

Grupy `imagery` (orto PL arkusze i wycinek WCS, orto CZ SM5, intensity, true-orto, oblique-orto), `maps` (topographic PL BDOT10k i CZ ZTM) i `geodesy` (control PL/CZ, geoid PL/CZ) wraz z `list-sources`. Typowo: pierwsze pobranie, powtorzenie (lokalne), `--check-updates`, `--upgrade`, `--force`, offline (`unshare -rn`), `--json` (schema pierwszy klucz, kod wyjscia, stderr), `--help`. Brzegi: pogranicze PL-CZ pod `--country auto`, bbox w EPSG:4326/2178/3045/5514, morze, obszar bez danych, zly produkt/flaga/CRS/godlo, granice lat, `--all-campaigns`/`--full-sheet`, bbox na styku arkuszy, bbox minimalny i zerowy, geometria GPKG/SHP, plan aktualizacji, manifest projektu, Ctrl-C/SIGKILL/SIGTERM, brak miejsca, `-o` niedostepny, rownolegle uruchomienia.

Wolumen: **397 wywolan CLI zapisanych w `cases.jsonl`** (plus kilka doraznych: zimny cache, 3 rownolegle, petla `parse`; 263 online, 134 offline pod `unshare -rn`; 177 dokumentow `--json`, wszystkie poprawne JSON-em, `schema` pierwszym kluczem, `\n` na koncu), 13 porownan biblioteka-CLI, 20 przykladow z katalogu i `--help`, 118 sidecarow. Kody wyjscia CLI: 0 x 202, 2 x 119, 1 x 68, 130 x 5, zabite SIGKILL (-9) x 2, zabite SIGTERM (-15) x 1.

**Podsumowanie.** Tabela ponizej ma **70 scenariuszy**: **53 zgodnych z oczekiwaniem/dokumentacja, 17 z odchyleniem**. Znaleziska: **P1: 0, P2: 1, P3: 15**. Zadne dane nie byly bledne: wszystkie pobrane pliki maja zgodne SHA-256/rozmiar/georeferencje.

## Srodowisko

- Kartograf 0.8.0 z wheel (czysta instalacja `[mcp]`), `.../venv/bin/kartograf` i `.../venv/bin/python`; Python 3.13.5, rasterio 1.5.2, pyproj 3.8.0, numpy 2.5.4, pyogrio 0.13.0; GDAL (`ogr2ogr`) systemowy do przygotowania geometrii testowych. pyproj bez siatek CZ (`cz_cuzk_table_-y-x_3_v1710.tif`) i bez sieci PROJ.
- cwd: katalog plastra (swiezy cache `.kartograf_cache.db`, lokalnie; podkatalog `cold/` dla zimnego cache). Dane: wylacznie `<katalog-danych>` (udzial cifs; dowiazania twarde dzialaja, `du` liczy kazda sciezke osobno: 1,8 GB wg `du`, ok. 0,95 GB bajtow unikalnych = suma plikow w `versions/`).
- Uslugi: GUGiK (WMS/WFS/WCS/opendata), CUZK (ATOM, openzu, ArcGIS). Uwagi o stanie uslug: WCS true-orto 298 s dla 100x100 m (14 s 2026-10-17), pobranie ZIP orto CZ 91 s (22 s wtedy), geoid CZ 140 s; GUGiK dwa razy `zerwane albo odrzucone polaczenie` (T3 1. proba, O1/BD1 jedno ponowienie), potem OK - to awarie uslugi, nie Kartografu.
- Uwaga procesowa: po komunikacie koordynatora (limit rozmiaru) przeprowadzilem test Ctrl-C na obszarze 12x12 km; SIGINT nie zatrzymal pobierania (znalezisko P2-1), zanim zabilem proces pobralo sie ok. 470 MB (wg `du`). Dane usunalem, razem z innymi tymczasowymi (przerwania, rownoleglosc).
