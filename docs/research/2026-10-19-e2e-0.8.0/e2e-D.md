# E2E Kartograf 0.8.0 - wycinek D: boundaries, cadastre, models3d, hydro, names (+ list-sources)

Data: 2026-10-19. Wheel `kartograf-0.8.0` z `git archive HEAD` (develop @ e019126a), czysty venv Python 3.13.5 z extra `[mcp]`. Dane pod `<katalog-danych>` (udzial SMB), cache metadanych lokalny (`.kartograf_cache.db` w katalogu roboczym).

## Zakres

Grupy `boundaries` (admin PL/CZ: wojewodztwo, powiat, gmina, jednostka-ewidencyjna, obreb / kraj, okres, obec, katastralni-uzemi; addresses; special; geomorphology - 7 poziomow), `cadastre` (map PL: EGiB obszar i powiat; map CZ: KU w SHP/DXF/DGN/VFK, KU z obszaru; prices PL: powiat i obszar), `models3d` (buildings LoD1 2019/2021/2022/2024 i LoD2 2017, mesh, trees), `hydro` (network CZ: obszar i plik krajowy), `names` (geographic PL/CZ, world, pliki krajowe PL i CZ) oraz `list-sources` wszystkich 5 grup.

Dla kazdego produktu: pierwsze pobranie, powtorzenie (lokalnie), `--check-updates`, `--upgrade`, `--force`, powtorzenie offline (`unshare -rn`), `--json` (schema pierwszy, kod wyjscia), kontrola GPKG (GDAL/pyogrio: warstwy, liczba obiektow, CRS) i sidecara `kartograf-meta/1`. Przypadki brzegowe: granica PL-CZ pod `--country auto` (Cieszyn / Cesky Tesin), bbox EPSG:4326/2178/3045/5514, obszar na morzu, obszar bez danych, bbox 1-5 m i zerowy, bledne wartosci opcji, limity obszaru (100 plikow / 10 GB), `--sheet` (PL-1992 i PL-2000), `--geometry` (GPKG z warstwami, SHP), `--workers`, `-q`, plan (`--check-updates --plan` i `--upgrade --plan` z czescia pozycji), Ctrl-C, rownolegle uruchomienia, manifest projektu, parzystosc CLI == biblioteka == MCP.

## Srodowisko
